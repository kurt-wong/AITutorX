## 1. Preprocessing 已提供的结构证据（Directly Verified）

### 1.1 Core concept definition — `Papers/prd.md` §2.2

**Label**: `DOCUMENT-BACKED` + `DIRECTLY VERIFIED`（本轮亲读 `prd.md:84-88`）

```text
standalone_question：
  无共享材料的独立题，一个单元 = 题干＋选项（选择题）＋配图/表格＋答案（＋详解可选）。

composite_question：
  若干小题共享同一段前置材料（文言文/现代文阅读、英语阅读/完形/语法填空/七选五、
  理化实验、工艺流程、材料题……脱离材料无法作答）。
  整块就是一道题，不拆子题。

嵌套：composite 中 material ⊆ questions
（材料是题目区的前段/内段；完形填空里带空格的文章本身即题目）
```

**Owner Decision 对照**（X2.6-UQ-01）:
| Historical preprocessing | Owner current model | Gap |
|--------------------------|---------------------|-----|
| Unit = 切分单元，含 `unit_type` | Unit = 组织/分组层 | 方向一致；词面不同 |
| Composite = 共享前置材料，脱离材料无法作答 | Composite = 共享结构 + 不可剥离解答依赖 + 显式分组 | Historical 偏 material-centric；Owner 扩展了 prerequisite/context/explicit grouping |
| 整块一道题，不拆子题 | Question 是最小粒度；Composite Unit 下可有多个 Question（各自 Question-Type） | Historical 产物 = 原子单元；Owner 目标模型 = Unit→Questions 层次 |
| 无独立 independent-answerability 字段 | Owner 明确要求该判据 | Manifest schema 无该字段 |

**结论**: preprocessing **已经** 发现并输出 Composite 语义证据；历史定义 **不等于** Owner 当前定义的全部。

**核心结论（回答任务书 Q3）**:
> preprocessing **已经提供了大量 Composite 语义证据**，不是「不知道 Unit-Type」。
> 证据形态 = LLM 判断 + 结构字段（unit_type / material_lines / question_numbers / original_question_type）。
> 历史证据 **偏 material-sharing 操作化**；Owner 当前模型所需的 independent-answerability / explicit-grouping / prerequisite-context **区分尚未结构化**。
