## 7. Historical Reprocessing Principle

对于现有 V3 / preprocessing 中已存在的 `standalone_question` / `composite_question`：

**不要**把它们设计成 X 的永久 canonical mapping ontology。

历史数据处理路径：

```text
Historical / Legacy Input
        ↓
    preprocessing
        ↓
  V3 / X new pipeline
        ↓
Semantic Annotation
        ↓
    Resolver
        ↓
       IR
        ↓
   Compiler
        ↓
     Gate
        ↓
  Admission
        ↓
X Canonical Question / Unit
```

> **迁移的目标不是把旧 ontology 搬进新 ontology，而是让历史数据重新经过新的 canonical pipeline，由新管线产生新的 canonical semantics。**

旧 annotation 可以作为 provenance / historical evidence 保存，但不能成为 X canonical ontology 的 authority。
