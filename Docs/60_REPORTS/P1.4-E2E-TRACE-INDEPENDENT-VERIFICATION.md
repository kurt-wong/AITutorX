## 4. 关于 `2D.` / Q23 的一个**重要限定**（推翻我此前表述）

我此前把 Q23 与 Q4 都描述为「源中有内容、label 可**确定性**恢复」。
**「确定性」在 Q4/Q23 上不成立**：

- **Q4**：`2D.` 既可能是「`2` + 标签 `D`」，也可能是「C 正文尾部 `2` + `D.`」。
  源中**没有**任何东西能排除后者。P1.4-B 选择前者 —— 这是**判断**，不是确定性解析。
- **Q23**：L194 是无标签裸内容行。它也可以是 **C 的续行**（C 的式子与 L194 都是离子方程式）。
  源中**没有**任何东西能排除「C 续行」这一解释。P1.4-B 选择当作第 4 个选项 —— 同样是**判断**。
- **Q29**：`D 麦哲伦` 是**唯一真正确定性**的一例 —— 字母 `D` 作为 token 实际存在于源中，
  只有分隔符缺失。

**结论**：把三者统称为同一条「deterministic parser compatibility」是**不准确的**。
- Q29 = 真正的解析兼容（标签 token 在，仅缺分隔符）
- Q4 / Q23 = **在源本身有歧义时作出的解释选择**（结果恰好正确）

这直接影响 §12 的立项理由：若要泛化 Rule A/B，必须先说明**歧义消解规则**是什么，
而那已经不是「compatibility」，而是**架构决策**。
