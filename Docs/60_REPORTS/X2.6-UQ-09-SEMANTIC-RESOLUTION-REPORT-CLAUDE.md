## 3. Composite Unit Definition（语义基准）

> 若干 Question 共享材料、共享前提条件，或文档明确注明同组；并且组内 Question 脱离共享结构后无法独立完成解答时，形成 Composite Unit。

**形成依据（OR）**:
```text
shared Material
OR shared prerequisite/context
OR explicit grouping
OR non-independent answerability caused by shared structure
```

**非充分依据**:
```text
consecutive numbering
page adjacency
section adjacency
```

**机械等价禁止**:
```text
存在 shared field ≠ Composite（须有语义解答依赖）
```

## 4. Independent Answerability Dependency

> Question 脱离组内共享 Material / prerequisite / context 后无法独立完成解答 = 不可剥离的解答依赖。

**实现禁止**:
```python
if any(question_cannot_answer_alone):
    unit_type = "composite"   # 禁止
```

**必须区分（不得混成一个字段）**:
```text
共享 / 依赖 / 不可独立解答 / 显式分组
```

**当前系统状态**: manifest / IR **无** structured answerability 字段；preprocessing prompt 有 **implicit**「脱离材料无法作答」。
