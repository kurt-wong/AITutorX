## B. Ontology Model

### B.1 Four Concepts

```text
Question
    = 语义题目对象 / semantic question object
    = Admission 后 canonical domain entity
    = 回答"这是哪个题目/语义对象？"
    ≠ Unit Type，≠ 考试题型枚举

Question Type
    = 考试语义 / exam question type
    = closed set（以 Frozen Spec 权威定义为准）：
      {single_choice, multiple_choice, true_false, fill_in,
       short_answer, essay, cloze, reading, grammar_fill,
       vocabulary_fill, seven_to_five, reading_expression}
    = source: V3 CANONICAL_TYPES (compile/__init__.py) / DISPLAY_CONTRACT §0.2

Unit
    = V3 中用于处理、组织、编译和最终物化的结构单元
    = 与 Question 存在语义关联，但不是同一个概念

Unit Type
    = Unit 的结构形态
    = canonical closed set（V3 唯一正式闭集）：
      {standalone_unit, composite_unit}
    = source: V3 UNIT_TYPES (gate/__init__.py:18)
```

### B.2 Orthogonality

```text
Question Type ⟂ Unit Type

Question Type 描述"是什么题型"
Unit Type 描述"Unit 的结构形态"

不得建立：Question Type → Unit Type 映射
不得从 Unit Type 推导 Question Type
不得把 standalone_question / composite_question 作为 Question Type 或 Unit Type
```

### B.3 Producer Legacy Vocabulary

```text
standalone_question
composite_question
```

**Classification**：

```text
Layer          = Producer / preprocessing / historical corpus / interface vocabulary
NOT V3 Question Type   = NO
NOT V3 Unit Type       = NO
NOT V3 canonical enum  = NO
```

**Boundary**：

```text
Producer vocabulary
        ↓
interface / normalization boundary
        ↓
V3 canonical vocabulary

Producer 可以保留历史/接口 vocabulary；
但这些词不得污染 V3 内部 Question Type / Unit Type ontology。
```
