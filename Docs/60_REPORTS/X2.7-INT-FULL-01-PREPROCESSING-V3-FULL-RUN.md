1. **基线路径的端到端链路未走通到最后。** `runner_b2`（唯一含 IR → Compiler → Gate → Candidate 的入口）在默认正式路径上 **172/172 全部停在 M5 Identity Gate**，下游 Annotation / Resolver / Resolved Span / IR / Compiler / Gate / Admission **全部 `NOT REACHED`**（不是 0）。停止原因二分：85 件 `manifest_sha_missing`、87 件 `semantic_pending`（`ir_absent`）。
