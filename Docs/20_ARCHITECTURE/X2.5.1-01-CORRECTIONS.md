| Adversarial tests | `test_adversarial_ir_identity.py` / `test_adversarial_raw_bytes.py` / `test_adversarial_manifest.py` | 断言 identity 路径 **无** `canonical_json` 调用 | DIRECTLY VERIFIED |

### Corrected identity semantics（禁止弱化治理定义）

```text
Governance / Contract definition（NOT weakened）:
  cross-system source identity = specified raw/original source identity
  source_content_sha256 = SHA256(original source bytes), 64 lower hex

Producer:
  source_content_sha256
  = SHA256(OCR markdown bytes)
  （manifest 接口键；87 回填面）

V3:
  original_sha256
  = SHA256(original uploaded source bytes)
  （V3 Document / seal 层字段语义）

X2.5.1 rule:
  Do NOT imply that these hashes MUST be equal.
  Same bytes ⇒ same hash is definitional.
  Different byte domains (OCR md vs original upload) ⇒ not automatically equal.
  Path is locator, not identity.
```
