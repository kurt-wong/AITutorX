### 3.1 SHA256 语义是否三系统一致？

| System | SHA256 usage | Input bytes | Consistent with Contract key? |
|--------|--------------|-------------|-------------------------------|
| Contract / AITutorX governance | `source_content_sha256` | original source bytes（md 面执行口径） | **定义权威** |
| preprocessing manifest（87） | `source_content_sha256` 字段 | 源 md 原始字节 | **YES**（87/87 回填；磁盘抽样亲验） |
| preprocessing IR | `source_sha256` + `provenance.source_version` | 源 md 原始字节 | **同值语义；键名不同** |
| preprocessing OCR list | `source_sha256` | **PDF** bytes | **NO**（分层；禁混用） |
| V3 consumer path（`hashing.py` / `runner.py`） | `file_sha` / `documents.original_sha256` | canonical_json 包裹 joined-text | **NO**（Contract OBSERVED） |
| V3 identity modules M1–M5（`cc12d79`） | designed for raw bytes sha | raw bytes（设计目标） | 设计对齐；实现验收属 Guardian/Owner，**非本阶段宣布 VERIFIED for migration** |

**结论（X2.5）**：跨系统 identity **语义在 Contract 层已冻结且一致**；**实现层三系统并非同一 SHA256 语义自动成立**。迁移前必须区分：定义一致 ≠ 实现一致 ≠ 已验证可迁移。
