| Fact | Label |
|------|-------|
| 正常 script path：`annotation_adapter` 先把 `composite_question` 构造成 payload `composite_unit` | `DIRECTLY VERIFIED` |
| IRBuilder 输出域仅 `{standalone_question, composite_unit}` | `DIRECTLY VERIFIED` |
| 故 Gate table 在该路径上 **不会收到** `composite_question` | inference from above |

### ACTIVE-risk 论据

| Fact | Label |
|------|-------|
| Gate `.get(x,x)` passthrough：若 IR 值为 table 外字符串，candidate 可存非 `UNIT_TYPES` 值 | `DIRECTLY VERIFIED` |
| 存在不经 adapter 的 IR 构造可能（未来 migration import / JSON load） | DSH INFERENCE + `UNKNOWN`（本轮未观察到该 production 入口） |
| runner_b2 else 分支：任何非 standalone IR → `composite_unit`（含异常值被 **洗成** composite） | `DIRECTLY VERIFIED` |
| adapter else：任何非 composite manifest type（含 `andalone_question`/`unknown`）→ **洗成** standalone | `DIRECTLY VERIFIED` |

### Classification

```text
Gate mapping 缺 composite_question:
  - 在 observed adapter→IRBuilder→GateService path 上 = LATENT（implementation observation）
  - 在「IR 可能不经 IRBuilder/adapter 构造」的场景下 = ACTIVE-risk（path existence = UNKNOWN）
```
