## OD-MAP-01 — Legacy 名称不能直接等同于 Canonical 名称

**Owner Decision**: `同意`（批准 Resolution Package §3 提案）

**Recorded**:

历史名称：
```text
standalone_question
composite_question
andalone_question
```

不能直接通过字符串映射变成：
```text
standalone_unit
composite_unit
```

**正确原则**:
```text
历史名称
    ↓
保留历史信息
    ↓
作为证据
    ↓
根据实际语义证据判断
    ↓
standalone_unit / composite_unit
```

如果无法可靠判断：
```text
→ UNKNOWN
→ 待人工判断
```

**特别禁止**:
```text
standalone_question → standalone_unit    （无条件映射）
composite_question → composite_unit      （仅因名称相似的无条件映射）
```

`andalone_question` 必须遵守 D8（Preserve + Isolate + Observe；NON-CANONICAL LEGACY OBSERVATION）。

**Label**: `OWNER DECISION FINALIZED`

## OD-UNKNOWN-01 — 判断不了就 UNKNOWN

**Owner Decision**: `同意`（批准 Resolution Package §4 提案）

**Recorded**:

如果系统无法可靠判断一个 Unit 属于：
```text

```

```text

```

**不得**:
```text

```

**正确原则**:
```text

   ↓
UNKNOWN
   ↓
进入待人工判断
   ↓
明确决策
   ↓
standalone_unit / composite_unit
```

UNKNOWN 必须能够在系统中**真实存在、传递和被处理**，而不能只是文档里的概念。

**Label**: `OWNER DECISION FINALIZED`
