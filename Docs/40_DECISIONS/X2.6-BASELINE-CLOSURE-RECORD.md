## 7. OD-2 ACCEPTED / CLOSED

### 7.1 Final Semantics

> `standalone_question` / `composite_question` 是 Producer / preprocessing / historical legacy vocabulary；它们可以存在于 Producer interface、historical corpus、legacy fixtures 和 migration evidence 中，但**不是** V3/X canonical Question Type，也**不是** V3/X canonical Unit Type。

进入 V3/X boundary 后必须进行 normalization：

```text
legacy Producer vocabulary
        ↓
boundary normalization
        ↓
canonical V3/X Unit Type
```

canonical Unit Type 只能是：`standalone_unit` / `composite_unit`

### 7.2 OD-2 is NOT a Mapping

**极重要**：不得把 OD-2 表述成：

```text
standalone_question → standalone_unit
composite_question → composite_unit
```

作为 canonical `Question Type → Unit Type` mapping。

> 这是 **legacy vocabulary normalization**，不是 canonical ontology mapping。
