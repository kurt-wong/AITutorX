## 2. 新增约束 `[PROPOSAL]`

### 2.1 GF-001 — Source Authority Model v0.2

| 变更 | 内容 | 对应 DSH/R |
|------|------|------------|
| **扩展角色** | 增补（不替换）：**GOV** Governance Document Authority；**EVD** Evidence Ledger Artifact；**EXT** External Capability（OCR 引擎、embedding、knowledge seed、DISPLAY_CONTRACT 等） | R7 |
| **PIS → Carrier 链接** | PIS 旁增加「载体可变、观测不可变」时间维（详 `04_LINEAGE_MODEL_V0.2.md`） | R2 |
| **Artifact Registry 四类** | Governance Authority Artifact / Evidence Artifact / Working Artifact / Temporary Artifact | R6 |
| **Untracked 引用三态** | 禁止引用 / 可引用（受限+登记）/ 必须登记 | R6 |

**角色完备性** `[FACT]`: V3_SPEC `50_Migration_Assets.md` §3 五类可复用资产在 GF-001 现行五角色中无稳定承接 → `[PROPOSAL]` 由 GOV/EXT/EVD 覆盖。

### 2.2 GF-002 — Artifact Lineage Specification v0.2

| 变更 | 内容 | 对应 |
|------|------|------|
| **Carrier Observation Model** | Carrier / Observation / State / Restoration Event | R1–R3 |
| **Lineage 升级** | `path→hash→identity` → `logical identity → carrier observation → content fingerprint → authority state`（**不废除** hash 锚） | R2 |
| **双验证分列** | Interface Integrity ≠ Locator Integrity + 状态枚举 | R8 |
| **Completeness Class 挂载点** | A/B/C/D 挂在 **Observation** 上，不挂在裸路径 | R1/R2 |
| **hash 书写规范强化** | 引用 hash 必须带 `hash_meaning` + `bytes_kind` + 观测时点或 `observation_id` | R1；关联 OQ-GF-003（**不关闭**） |

### 2.3 GF-003 — Migration Evidence Contract v0.2

| 变更 | 内容 | 对应 |
|------|------|------|
| **EvidencePackage v0.2** | 字段扩展见 `03_EVIDENCE_PACKAGE_V0.2_SCHEMA.md` | R1/R4/R11 |
| **Known Issue Binding** | Asset → KnownIssue → Disposition | R5 |
| **approval_block 有效性** | F4 无效时必须 `invalid_without_charter` | R10 |
| **失败处置增补** | 迁移后 `post_copy_sha256` 漂移 → BLOCK + `LINEAGE_BROKEN` | R11 |
| **Coverage_class 通用化** | 不再仅 OCR 子类必填 | R8 |

**硬化句** `[PROPOSAL]`（写入 GF-000/003 时用语）:

```text
GF 状态升为 Frozen Governance Baseline  ≠  Migration Gate 获得执行力。
在 OQ-GF-014 / OQ-GF-015 / F4 / F5 关闭前，任何 “Gate 9 passed” 声明无效。
```

依据 `[FACT]`: REPORT-I F4「Charter 未设立」；F5「本 REPORT-I 为草案」；GF-003 §7 已述 F4 前 Gate 9 无效。

### 2.4 GF-004 — Migration Boundary Definition v0.2

| 变更 | 内容 | 对应 |
|------|------|------|
| **对齐 V3 50 §3** | 外部能力 / knowledge seed / DISPLAY_CONTRACT / Golden Corpus / 失败教训（只读不移植） | R9 |
| **补类** | attacks/、logs/；frontend 维持 DEFAULT-NO（OD-010 未决 `[FACT: REPORT-I Cluster E]`） | R9 |
| **证据类 YES 过滤** | DQ/审计 JSON → CONDITIONAL + known_issue 绑定 | R5/R9 |
| **数据本体默认 NO 不变** | 服从 OQ-GF-002 未决 `[FACT: OD-009/F8 open]` | 保留 |
| **V2 绝不迁不变** | 服从 V3 50 §5 `[FACT]` | 保留 |

### 2.5 GF-005 — Open Questions Registry v0.2

| 变更 | 内容 | 对应 |
|------|------|------|
| **增列 `blocking_scope`** | any-migration / data-only / code-only / claim-only / doc-only `[PROPOSAL]` | R12 |
| **零关闭** | 不改任何条目 Status 为 CLOSED | 纪律 |
| **`[PROPOSAL]` 可选新条目** | OQ-GF-019 rollback / 迁移后验证标准 | R11 |

**现行统计** `[FACT]`: GF-005 §1 — 登记 18 条；OPEN-BLOCKING 9 条。
