1. 【答案】B

【解析】

【详解】A. 在标况下，氯气的密度大于空气的密度，A 正确；

B. 电解质是溶于水或在熔融状态下能够导电的化合物；非电解质是溶于水或在熔融状态下不能够导电的化合物；而氯气为单质、氯水为混合物，B 错误；

C. 氯气能溶于水和水反应，故实验室不能用排水法收集氯气，C 正确；

D. 久置氯水中次氯酸分解生成强酸盐酸，导致溶液酸性变强，D 正确；

故选 B。

2. 【答案】A

【解析】

【详解】A. 钠与盐酸反应生成氯化钠，钠与氯气反应生成氯化钠，A 正确；

B. 铁与盐酸反应生成氯化亚铁而不是氯化铁，B 错误；

C. 铁与氯气反应生成氯化铁而不是氯化亚铁，C 错误；

D. 铜为不活泼金属与盐酸不反应，D 错误；

故选 A。

【解析】

【详解】A. 新制氯水中次氯酸易见光分解，故应保存在棕色试剂瓶中，并放置于阴凉处，A 正确；

B. 钠会和水生成可燃性气体氢气，钠和氧气生成的过氧化钠会和二氧化碳生成助燃性氧气，故着火时不可以用干冰或水来灭火，B 错误；

C. 氢氧化钙微溶于水，工业上用氯气和石灰乳反应制备漂白粉，C 错误；

D. 液氯没有漂白性，不能使干燥的红布条褪色，而氯水可以，D 错误；

故选 A。

4. 【答案】C

【解析】

【详解】A．氯气和水反应生成盐酸和弱酸次氯酸： $  \text{Cl}_2 + \text{H}_2\text{O} = \text{H}^+ + \text{HClO} + \text{Cl}^-  $，A 错误；

B．浓盐酸与  $  \text{MnO}_2  $ 制  $  \text{Cl}_2  $ 需要加热， $  \text{MnO}_2 + 4\text{H}^+ + 2\text{Cl}^- \xrightarrow{\Delta} \text{Mn}^{2+} + 2\text{H}_2\text{O} + \text{Cl}_2 \uparrow  $，B 错误；

C．向溴化亚铁溶液中通入少量氯气，氯气首先和亚铁离子生成铁离子，而溴离子没有参加反应： $  2\text{Fe}^{2+} + \text{Cl}_2 = 2\text{Fe}^{3+} + 2\text{Cl}^-  $，C 正确；

---

## 【小问 2 详解】

①Fe³⁺的产生不能判断FeO₄²⁻与Cl⁻一定发生了反应，根据资料“K₂FeO₄在酸性或中性溶液中快速产生O₂”，自身被还原成Fe³⁺，根据得失电子守恒、原子守恒和电荷守恒，可能的反应为4FeO₄²⁻+20H⁺=3O₂↑+4Fe³⁺+10H₂O。

C 中溶液加入稀 H₂SO₄ 发生反应： $  \text{ClO}^- + \text{Cl}^- + 2\text{H}^+ = \text{Cl}_2 \uparrow + \text{H}_2\text{O}  $，产生 Cl₂ 会干扰判断；已知： $  K_2\text{FeO}_4  $ 微溶于 KOH 溶液，在碱性溶液中较稳定；故用 KOH 溶液洗涤的目的是除去 KClO、排除 ClO⁻ 的干扰，同时保持 K₂FeO₄ 稳定存在；

②制备 K₂FeO₄ 的原理为  $ 3\mathrm{Cl}_2 + 2\mathrm{Fe(OH)}_3 + 10\mathrm{KOH} = 2\mathrm{K}_2\mathrm{FeO}_4 + 6\mathrm{KCl} + 8\mathrm{H}_2\mathrm{O} $，在该反应中 Cl 元素的化合价由 0 价降至 -1 价，Cl₂ 是氧化剂，Fe 元素的化合价由 +3 价升至 +6 价，Fe(OH)₃ 是还原剂，K₂FeO₄ 为氧化产物，根据同一反应中，氧化性：氧化剂 > 氧化产物，得出氧化性 Cl₂ > FeO₄²⁻；

根据方案Ⅱ，方案Ⅱ的反应为  $ 2\text{FeO}_4^{2-} + 6\text{Cl}^- + 16\text{H}^+ = 2\text{Fe}^{3+} + 3\text{Cl}_2 \uparrow + 8\text{H}_2\text{O} $，由方案Ⅱ得出氧化性  $ \text{FeO}_4^{2-} > \text{Cl}_2 $，实验表明， $ \text{Cl}_2 $ 和  $ \text{FeO}_4^{2-} $ 氧化性强弱关系相反；对比两个反应的条件，制备  $ \text{K}_2\text{FeO}_4 $ 在碱性条件下，方案Ⅱ在酸性条件下；说明溶液的酸碱性的不同影响物质氧化性的强弱。
