（2）取 $BC$ 的中点 $F$，连接 $AF$，因为底面 $ABCD$ 为菱形且 $\angle ABC = \frac{\pi}{3}$，所以 $\triangle ABC$ 为等边三角形，所以 $AF \perp BC$，所以 $AF \perp AD$，如图建立空间直角坐标系，令 $AB = PA = 2$，则 $D(0,2,0)$，$C(\sqrt{3},1,0)$，$B(\sqrt{3},-1,0)$，$E\left(\frac{\sqrt{3}}{2},\frac{1}{2},1\right)$，所以 $\overrightarrow{DE} = \left(\frac{\sqrt{3}}{2},-\frac{3}{2},1\right)$，$\overrightarrow{BC} = (0,2,0)$，$\overrightarrow{EC} = \left(\frac{\sqrt{3}}{2},\frac{1}{2},-1\right)$，设平面 $EBC$ 的法向量为 $\vec{n} = (x,y,z)$，所以 $\begin{cases} \overrightarrow{BC} \cdot \vec{n} = 0 \\ \overrightarrow{EC} \cdot \vec{n} = 0 \end{cases}$ 即 $\begin{cases} 2y = 0 \\ \frac{\sqrt{3}}{2}x + \frac{1}{2}y - z = 0 \end{cases}$，令 $x = 2$ 则 $y = 0$，$z = \sqrt{3}$，所以 $\vec{n} = (2,0,\sqrt{3})$，设直线 $ED$ 与平面 $EBC$ 所成角为 $\theta$，则

 $$ \sin\theta=\frac{\left|\overrightarrow{DE}\bullet\overrightarrow{n}\right|}{\left|\overrightarrow{DE}\right|\bullet\left|\overrightarrow{n}\right|}=\frac{\left|\frac{\sqrt{3}}{2}\times2+1\times\sqrt{3}\right|}{\sqrt{2^{2}+\left(\sqrt{3}\right)^{2}}\times\sqrt{\left(-\frac{3}{2}\right)^{2}+\left(\frac{\sqrt{3}}{2}\right)^{2}+1^{2}}}=\frac{\sqrt{21}}{7} $$

解：（I）由 $ a_{n}=3n-1 $可得 $ \left\{a_{n}\right\} $为递增数列，所以

 $$ b_{n}=\max\left\{a_{1},a_{2},\cdots,a_{n}\right\}-\min\left\{a_{1},a_{2},\cdots,a_{n}\right\}=a_{n}-a_{1}=3n-1-2=3n-3, $$ 

所以 $ b_n = 3n - 3, n \in \mathbb{N}^* $

（Ⅱ）因为  $ \max\left\{a_{1},a_{2},\cdots,a_{n}\right\}\leq\max\left\{a_{1},a_{2},\cdots,a_{n+1}\right\}(n=1,2,3,\cdots) $

 $$ \min\left\{a_{1},a_{2},\cdots,a_{n}\right\}\geq\min\left\{a_{1},a_{2},\cdots,a_{n+1}\right\}\left(n=1,2,3,\cdots\right) $$ 

所以  $ \max\left\{a_{1},a_{2},\cdots,a_{n+1}\right\}-\min\left\{a_{1},a_{2},\cdots,a_{n+1}\right\}\geq\max\left\{a_{1},a_{2},\cdots,a_{n}\right\}-\min\left\{a_{1},a_{2},\cdots,a_{n}\right\} $,

所以 $ b_{n+1} \geq b_n (n=1,2,3,\cdots) $.

又因为 $ b_1 = a_1 - a_1 = 0 $，所以 $ \max\{b_1, b_2, \cdots, b_n\} - \min\{b_1, b_2, \cdots, b_n\} = b_n - b_1 = b_n $，

所以 $ \left\{b_{n}\right\} $的“收缩数列”仍是 $ \left\{b_{n}\right\} $.

（III）由 $ S_{1}+S_{2}+\cdots+S_{n}=\frac{n(n+1)}{2}a_{1}+\frac{n(n-1)}{2}b_{n}(n=1,2,3,\cdots) $可得

当n=1时， $ a_{1}=a_{1} $;

当n=2时， $ 2a_{1}+a_{2}=3a_{1}+b_{2} $，即 $ b_{2}=a_{2}-a_{1} $，所以 $ a_{2}\geq a_{1} $；

当n=3时， $ 3a_{1}+2a_{2}+a_{3}=6a_{1}+3b_{3} $，即 $ 3b_{3}=2(a_{2}-a_{1})+(a_{3}-a_{1})^{*} $，

 $ a_{1} \leq a_{3} < a_{2} $，则 $ b_{3} = a_{2} - a_{1} $，所以由（*）可得 $ a_{3} = a_{2} $，与 $ a_{3} < a_{2} $矛盾；

若 $ a_3 < a_1 \leq a_2 $，则 $ b_3 = a_2 - a_3 $，所以由（*）可得 $ a_3 - a_2 = 3(a_1 - a_3) $，

所以 $ a_3 - a_2 $与 $ a_1 - a_3 $同号，这与 $ a_3 < a_1 \leq a_2 $矛盾；

若 $ a_3 \ge a_2 $，则 $ b_3 = a_3 - a_1 $，由（*）可得 $ a_3 = a_2 $。
