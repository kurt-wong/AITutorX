1. B

3. C

【分析】

1.

读表可知，1953年中国人口自然增长率为22.2‰，人口自然增长率高，结合所学地理知识可知，该时期我国的人口增长模式应为传统型，表现为高出生率、低死亡率、高自然增长率，故选B。

2.

1982 年以来，随着改革开放政策的实施，我国东南沿海以及城市地区经济快速发展，就业岗位多，收入水平更高，吸引了农村人口大量迁入城市，所以主要影响因素是经济因素，D 正确；社会文化因素、政治因素、生态环境因素等均非最主要的影响因素。故选 D。

3.

“一对夫妇可坐育两个孩子”政策的实施，一定程度上可提高人口出生率，提高人口自然增长率，缓解我国人口老龄化问题，有利于我国人口长期均衡发展，C 正确，D 错；人口合理容量是按照合理的生活方式，保障健康的生活水平，同时又不妨碍未来人口生活质量的前提下，一个国家或地区最适宜的人口数量，全面实施“一对夫妇可坐育两个孩子”政策并不能增加我国的人口合理容量，A 错；老年人口的比重可能会减小，但老年人口的数量不一定减少，B 错。故选 C。

【点睛】

由于人口红利即将消失（人口红利：劳动力资源相对丰富、抚养负担轻、于经济发展十分有利的“黄金时期”，人口经济学家称之为“人口红利”），人口老龄化激增。一方面，劳动年龄人口比重下降，另一方面，老龄化加快带来养老问题日益突出，正是在这样的背景下，我国提出了全面开放二孩政策。
